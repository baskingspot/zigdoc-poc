## Windows, and a bundle that carries its license

This release ships a Windows zip, built by the same job as the other platforms. Every archive now holds the `LICENSE` next to the program, as MIT requires of a copy.

## Changes

- The archive layout and the release notes are the org's, set by the shared release workflow, not by this repo.
- `just release-build TARGET DIR` only builds into a prefix. Bundling happens in the workflow.
